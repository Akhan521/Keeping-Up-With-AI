# Index

Every tool, concept and synthesis page, grouped by topic. One line per page: wikilink, page type, one-line summary. Rules live in `CLAUDE.md` under *index.md and log.md*.

## claude
- [[Claude Code Mods]] (tool): In-process JS/TS plugins that hook Claude Code's events to rewrite prompts, guard tool calls, draw UI or replace built-ins; powerful and not sandboxed.

## llm-wiki
- [[LLM Wiki Pattern]] (concept): An LLM builds and maintains a persistent, interlinked markdown wiki from sources, compiling knowledge once and keeping it current instead of re-retrieving it per query.
